# 从纸质个性化材料到墨水屏读书器的改进方案

## 原有模式（论文实践）

1. AI依托学情数据为每位学生生成分层学案、错题包、阅读清单。
2. 打印成纸质材料分发。
3. 小班使用个性化纸质包进行针对性辅导。
4. 大班讲授共性内容。
5. 教师审核AI初稿，聚焦概念建构与价值引导。

优点：减少屏幕时间、保护视力、校外学生也能使用。  
不足：打印成本高、内容更新慢、无法即时反馈、无法动态调整。

## 改进后的墨水屏模式

| 环节 | 纸质方案 | 墨水屏方案 |
|------|----------|------------|
| 内容生成 | AI生成后打印 | AI生成后通过5G/物联网下发到设备 |
| 分发 | 人工打印分发 | 设备自动同步（低功耗） |
| 使用场景 | 小班纸质包 | 小班墨水屏阅读 + 即时批注/反馈 |
| 更新频率 | 按周/单元 | 可按课、按天、按反馈即时更新 |
| 反馈闭环 | 人工收集 | 设备端操作数据自动回传 |
| 视力保护 | 纸质 | E-Ink 护眼，接近纸质 |
| 成本 | 持续打印耗材 | 一次硬件投入，长期低运维 |

## 推荐设备形态

- 独立手持阅读器（优先）
- 校牌/校卡形态（轻量）
- 手表形态（极简信息）
- 支持彩色与黑白 E-Ink

## 推送算法初步思路

1. 输入：学情数据（错题、掌握度、阅读进度、教师标注）
2. 模型：推荐系统 + 知识图谱 + 大模型内容生成
3. 输出：个性化内容包（阅读材料 + 练习 + 错题重练）
4. 反馈：阅读时长、完成率、正确率、教师批注 → 更新学生画像
5. 目标：逐步形成可解释、可干预的“终极学习算法”

## 与新建校区落地建议

- 规划阶段预留墨水屏充电与同步点（教室/宿舍）
- 小班空间按25–30人配置，方便设备使用与教师引导
- 大班仍以讲授为主，墨水屏作为课后/课前个性化补充
- 数据不出校，内容生成在本地AI中台完成

此方案保留了论文中“减负而非替代”“教师回归引导者”的核心取向，同时解决了纸质方案的更新与反馈痛点。
